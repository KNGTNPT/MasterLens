【安装】
1. 运行「安装 Install.command」。首次运行未公证版本，可能需要右键 → 打开。
2. VST3 / AU 复制到用户 Library/Audio/Plug-Ins；独立版放入 ~/Applications。
3. 重启 DAW，在 BerryStudio 下搜索 MasterLens，并放到母带链最后。

【基本使用】
默认逐位旁路、零延迟，只分析音频。试听、等响监听、参考 A/B 均需主动开启。
先播放 20–30 秒，再检查左侧 I / TP / LRA / PLR 和中央曲线。
底部比较基准可选平台、参考轨、专辑中位或手动参考。
文件 QC 支持 WAV / AIFF / FLAC 和递归文件夹；完成后自动加入当前专辑。
做下一张专辑前，请更换专辑名或清空上一张。
导出报告可得到 TXT / JSON / CSV / PDF 与 100 ms 原始序列。
CLI：MasterLensCli analyze <文件或文件夹> --json out.json

【快捷键】
空格保持，R 清零，1–9 切模块，0 曲风目标，F 文件 QC，Esc 停止试听，Cmd+E 导出。

【限制】
单声道 / 立体声；区域结果为 100 ms 包络估算；参考对齐为段落级包络匹配。
