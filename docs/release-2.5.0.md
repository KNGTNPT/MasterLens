# MasterLens 2.5.0

文件 QC 先看曲目，再听问题喵。

- **列表优先**：文件表保证默认窗口至少可见三行；证据详情可收起 / 展开，不再把曲目挤成一条。
- **播放状态**：选中文件后显示真实总时长，区分未加载、可播放、播放中；问题行单击即回听事件，右侧圆点仍负责复核。
- **状态先于分数**：文件表最后一列改为「建议回听 / 需修复 / 已复核 / 通过」；信号卡片也把 `风险 3` 改成「通过 / 建议回听 / 需修复」。
- **监听来源**：底部常驻「监听 · 工程 / 参考 / 问题片段 / 文件」；输出状态和监听来源分开。进入证据回听时同时显示文件名和时间段。
- **A/B 命名**：参考按钮改为「监听参考 / 监听工程」，读数快照 A/B 有明确标题。
- **读数就近**：响度页的综合、瞬时、短时读数把单位放回数值旁边。

二进制和测量算法没有改变。macOS Universal、Windows x64 / ARM64 安装包。macOS 仍为 ad-hoc 签名、未公证；Windows ARM64 仍为交叉构建，未做该环境实机测试。详细验证见 `docs/performance-2.5.0.md`。
