MasterLens 2.1：把“可能有问题”往前推一步，给出能复核的证据。

- 文件 QC 新增样本证据：头尾静音、内部数字静音、连续满刻度、直流偏移与剪辑边界；时间、声道和样本地址一起保留。内部静音只提醒试听，不替你判断音乐意图。
- 10 段单声道折叠检查，保留每段的能量占比与 Side 比例。离线频谱改为左右声道能量统计，反相内容不再先被求和消掉。
- 增益预算列出目标所需、峰值允许、预计可达与差额。平台页也改用受峰值约束的情景，修正“平台一定会限幅”和固定 Apple 曲尾一秒的旧说明。
- CSV + JSON 完整 QC 导出、源文件 SHA256、专辑证明持久化，以及 CLI 的 `--target` / `--ceiling` / `--fail-on`。坏输入或写报告失败会明确返回错误。
- 保留石墨灰与青绿，加入宽浅高光、接触阴影与柔和内凹；字距在字体单位中计算，100–200% 缩放一并检查；修正小窗口文字挤压与恢复英文设置后的按钮语言。BerryStudio 去掉空格，开发者改为 KNGTNPT 兰。

所有新检查都在本地运行，不用数据集、模型或外部编码器。截图来自本次实际构建；算法阈值、调研来源和验证范围见仓库文档。
