# MasterLens 2.3.1 验证记录

2026-11-03，基于在线 `main` / `v2.3.0` 的 `f1caad4261beee9f1810cf8ad2a086781d252574`。保留 2.3.0 的项目、证据回听、交付规格、监控与 CLI；本轮调整集中在显示和交互。

## 字体、缩放与标识

- Geist 三档字体从 11 / 13 / 20 提升至 **14 / 16 / 26px**。默认优先 125%，并适配显示器可用空间；旧工程首次迁移至新默认，之后保存用户选择。
- 设计画布固定 1120×700，原生缩放框保持 1.6 宽高比，最小 896×560。任意窗口尺寸都以同一比例缩放所有子组件及绘制，避免字号变大而行列留在原处。宿主强制其他宽高比时，采用较小比例完整放入可用区域。
- 中英文、五个缩放预设、11 页和三种频谱视图的检查通过：**13,190 项边界检查，0 失败**；另核对实际变换后边界，及连续缩放、等宽数字、字体配对差值。35 组 Release 布局 / 页面场景检查也全部通过，见 layout-2.3.1.json；18 张当前版本截图已更新。
- Logo 只旋转外环，中心点固定，每圈 8 秒；播放与停止的回归检查通过。UI 使用 FIFO 的采样进度及播放状态判定，不从音频线程调用绘图。
- 设置中保留中英文开发者，主界面副行只留 BERRYSTUDIO 与版本。关于页的工作室 SVG 根据提供的莓果图形重绘，字标由 Geist 字形生成轮廓，无背景矩形、无外部字体依赖；深浅主题分别准备缓存。
- 按钮使用预登记的固定容量状态表，加入轻量浅光影和阻尼回弹；动画不改变点击区域，不修改参数范围。

## 量表呈现与绘制时间

Apple Silicon macOS、Universal Release、1120×700 原生可见窗口。测试使用单独线程持续送入 48kHz / 512 样本的调幅立体声信号，在真实消息循环中统计约 5 秒的量表 paint 次数；随后用复用图像绘制整个组件树 30 次。这里将屏幕上的实际 paint 调用与数据更新计数分开报告。

| 页面 | 实际量表绘制 | 数据更新 | 整窗 paint p50 | p95 | 最慢一帧 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 响度 | 113.85 Hz | 114.1 Hz | 1.79 ms | 2.66 ms | 6.29 ms |
| 声场 | 113.88 Hz | 114.1 Hz | 1.10 ms | 1.25 ms | 4.20 ms |

可见窗口优先由 JUCE VBlankAttachment 跟随屏幕刷新；无显示时钟或时钟暂停时，由 90Hz 定时器后备驱动，避免两套时钟重复更新。当前机器达到至少 60 FPS 的目标。paint 调用不等于 GPU 扫描输出的每帧硬件验证；也不代表所有 DAW、低于 60Hz 的显示器或高负载下都保证 60 FPS。FFT 与问题归因继续以较慢节奏运行；Hold 时读数保持是预期行为。
