# MasterLens 2.3.0

曲线站前面，工作流也接起来喵。

- Precision Instrument 界面：频谱优先，Geist 内嵌排印，4px 网格，频谱页 32px 安全锚点；顶部标识放大，BERRYSTUDIO / 开发者 / 版本收在同一行。输出 SpectrumFifo 接通，原有响度、真峰值、M/S 与旁路行为不变。
- 项目文件与稳定曲目 ID：专辑快照、上一版、版本号、参考和证据一起保存；曲目 ID 不再使用毫秒时间戳。
- 文件 QC 证据复核：复核圆点、前后 4 秒循环预听、双击文件定位原文件，`reviewed` 随 CSV / JSON 导出。
- 自定义交付规格：采样率、位深、声道、命名模板、响度容差、真峰值；GUI 可导入 / 导出 JSON，CLI 使用 `--spec`。
- 文件夹监控：大小 + 修改时间指纹缓存，导出文件变化后自动复检；源文件 SHA256 仍是最终指纹。
- 可选编码后复测：CLI `--codec aac|mp3` 通过本机 ffmpeg 编码 / 解码后重测 LUFS 与真峰值；不伪造编码器试听。

2.3.0 是正式版，不是 prerelease。1–4 条参考轨、区域标记与问题片段循环沿用已有实现；实时局部选区仍是 100 ms 包络估算，精确结果以文件 QC 为准。未做商业代码签名、Apple 公证、云端编码或所有 DAW / 硬件实测；请用 `SHA256SUMS.txt` 核对下载文件。
