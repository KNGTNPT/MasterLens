MasterLens 2.0.3：把界面重新摆好，也把表头该跑的帧还给它。

- 横向模块导航、左侧主响度仪表、中央大图、底部参考与监听控制。石墨色面板、青绿色读数、自绘刻度与矢量图标，控件有自己的位置和轻微的光影。
- 响度与声场的表头独立刷新；FFT、事件归因、专辑门禁继续按较慢节奏计算，避免把分析开销塞进每一帧。
- 真峰值四相 FIR 改为连续窗口与并行累加，试听历史改为分块复制。测量标准、默认逐位旁路和零延迟保持原有行为。
- README 的界面图来自本次 2.0.3 构建；同机性能与验证范围见 docs/performance-2.0.3.md。

macOS 通用二进制（arm64 / x86_64）：VST3、AU、独立版和 CLI。Windows x64 / ARM64：VST3、独立版和 CLI。

macOS 打开 DMG 后运行「安装 Install.command」；Windows 运行对应架构的 EXE。两者安装后都请重启 DAW。本版本仍未做 Apple 公证或商业代码签名。SHA256SUMS.txt 可用于核对下载文件。
