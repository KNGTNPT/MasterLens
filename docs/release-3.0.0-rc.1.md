# MasterLens 3.0.0-rc.1

听吧，四种比较一起收好喵。

3.0-rc.1 把 2.7 挂账的四项监听能力一次补齐，并把前面的参考槽位留在原位：

- **频段独听**：频谱页「频段热力」的 10 段、低 / 中 / 高三段都可单击独听；4 阶 Butterworth（24 dB/oct），不做等响补偿，`Esc` 停止。独听只改监听输出，默认旁路不变。
- **选区等响**：时间页拖选后点「选区等响」。工程侧按 BS.1770-4 门限积分（−70 LUFS 绝对门、−10 LU 相对门）测选区，参考侧只解码 `OFS + 选区` 对应段，然后把差值写进当前槽位的 GAIN。工程声音不动，A/B 在等响下比较音色。
- **长文件流式播放**：独立版文件传输改成固定环形缓冲（约 8 MB / 4 s × 192 kHz），读取线程预读 3 s，音频线程只读原子下标；欠载输出静音并显示「缓冲中」，不再把整首歌读进内存，也不会阻塞音频回调。
- **编码 A/B**：文件 QC 用本机 ffmpeg 生成 AAC 256k / MP3 320k，解码回 float WAV 后在同一时间码切换 A 原始 / B 编码后；显示 ΔLUFS / ΔTP / 包体大小。缺少 ffmpeg 或超时会明确失败，不伪造结果。

范围说明：「选区」指 MasterLens 时间线拖选，不是宿主 loop（VST3/AU 没有通用 API）；长选区的循环交给宿主，≤ 10 s 可用 12 s 历史环试听。参考轨仍整段解码，超过 1 小时或 512 MB 会明确拒绝。macOS 继续 ad-hoc 签名、未公证；Windows ARM64 仍为交叉构建，未在 Windows on ARM 实机验证。详细验证见 `docs/performance-3.0.0-rc.1.md`。
