# MasterLens 3.0.0-alpha

先把数字和单位排好喵。

这是 3.0 的排版切片，不改音频、测量算法、项目格式或文件 QC 行为：

- 响度、真峰值、M/S、历史曲线、信号卡片、平台表、目标页逐页校正数字与单位的关系。
- 单位紧跟数值，使用较小的语义字号和一致的基线；数值保持 tabular numerals 与右对齐。
- 信号卡风险数字改为「通过 / 建议回听 / 需修复」。
- 平台归一化表重新分配列宽，目标、安全增益、预测 TP、差额都带单位。
- 保留 2.5.0 的文件 QC、监听来源、A/B 读数快照和 Windows 安装修复。

这是 **alpha**：2.6 / 2.7 的多参考、段落等响、长文件流式播放和编码 A/B 尚未包含。它们继续沿 3.0 路线开发，不能把本版当作完整 3.0。

macOS Universal、Windows x64 / ARM64 安装包。macOS 仍为 ad-hoc 签名、未公证；Windows ARM64 仍为交叉构建，未做该环境实机测试。详细验证见 `docs/performance-3.0.0-alpha.md`。
