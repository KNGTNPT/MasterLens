# MasterLens 2.3.1

字大一点，眼睛就轻松一点喵。

- 三档字体升至 14 / 16 / 26px，初次打开优先 125%，并适配当前屏幕。
- 拖动窗口时整张界面等比缩放，文字、控件和间距同步变化，支持 80–200% 缩放预设。
- 播放时左上圆环每 8 秒转一圈，中心不动；停止后保持角度。按钮加入浅光影与轻微阻尼回弹。
- 可见量表优先由屏幕垂直刷新驱动，后备 90Hz 时钟，以 60 FPS 为目标；分析与报告继续分频。
- 开发者移入设置；关于页加入透明莓果 SVG 工作室标识，字标采用矢量轮廓。
- 保留 2.3.0 的项目工作流、证据复核与回听、交付规格、文件夹监控和编码后复测。

提供 macOS Universal DMG、Windows x64 / ARM64 安装包。测量及界面验证见 [记录](performance-2.3.1.md)。不需要账号、数据集或模型，音频留在本地。macOS 包沿用 ad-hoc 签名，未做 Apple 公证；全部宿主 / 显示器的实机覆盖仍有限。
