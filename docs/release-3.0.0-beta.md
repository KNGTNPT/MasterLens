# MasterLens 3.0.0-beta

参考槽位和排版一起收好喵。

- 频谱页增加参考槽位、OFS（参考偏移）与 GAIN（匹配增益）；可快速切换多条参考轨，设置随工程状态保留。
- 设置页页脚：logo、BERRYSTUDIO、开发者、关闭按钮同一水平中线。
- 各页左栏及频谱页下方读数：数值与单位同一基线。
- 平台归一化下拉下沉，对齐 REF / CEIL 读数。
- 快照 A/B 文字在按钮内居中；时间页按钮与事件轴上下留白。
- 目标页曲风参照 / 平台要求行距按可用高度分散。

2.7 的长文件流式播放、编码 A/B、选区等响和频段独听仍未进入 beta。macOS Universal、Windows x64 / ARM64 安装包；macOS 仍为 ad-hoc 签名、未公证。详细验证见 `docs/performance-3.0.0-beta.md`。
