# MasterLens 2.0.1 界面参考调研

> 调研日期：2026-11-01。只作内部对照，不随产品分发；截图放在 `docs/ui-refs/`，不复制品牌 logo、配色或图形资产。
> 网络情况：官方产品页可访问；KVR / DuckDuckGo 有反爬限制，因此以官方图和产品页信息为准。部分交互细节来自长期公开的插件使用经验，已在条目中标注“推断”。

## 参考清单

### 1. oeksound soothe2 / soothe3
- 借什么：左侧一组大旋钮 + 右侧一张主导曲线图；图和参数的关系一眼可见，留白多，控件不抢读数。图优先、控制区退后。  
- 不借什么：浅蓝紫品牌色、软阴影大圆角、把参数值塞进每个控件旁的小胶囊。  
- 可量化特征：约 3 层表面；1 个主强调色（品牌蓝）；控件与面板圆角明显大于 8 px；图区占约 3/4 宽度；参数标签 10–12 px，读数 12–14 px；控件间距约 8–12 px。  
- 链接：https://oeksound.com/plugins/soothe3  
- 截图：`docs/ui-refs/soothe3.jpg`

### 2. FabFilter Pro-Q 4
- 借什么：整页以一张可交互的图为中心，顶部只用一条很薄的模式/预设带；数值编辑通过双击，不常驻一堆输入框。  
- 不借什么：彩色频段、过大的品牌字、满屏提示气泡。  
- 可量化特征：2–3 层表面；强调色集中在频段和选中态；圆角接近 4 px；顶部带高度约 32–36 px；网格 1 px 低对比；读数以 11–13 px 为主。  
- 链接：https://www.fabfilter.com/products/pro-q-4-equalizer-plug-in  
- 截图：`docs/ui-refs/pro-q4.jpg`

### 3. FabFilter Pro-L 2
- 借什么：把“当前值、目标、危险区”放在同一条水平刻度上；大读数只保留一个，其他信息降为次级。  
- 不借什么：深蓝黑底 + 亮蓝表头；多组彩色电平同时占据视觉中心。  
- 可量化特征：2 层表面；单侧强调色；刻度 10–11 px；主表占页面高度 50% 以上；控件行 28–32 px。  
- 链接：https://www.fabfilter.com/products/pro-l-2-limiter-plug-in  
- 截图：`docs/ui-refs/pro-l2.jpg`

### 4. iZotope Ozone 11（含“反面”观察）
- 借什么：模块之间的层级清楚，图、表、建议区有明确的阅读顺序；母带工具可以把多个判断放在一页但不互相打架。  
- 不借什么：信息过载、同屏多个高饱和状态色、把每个模块都做成有边框的卡片、建议文案过多。  
- 可量化特征（推断）：3 层以上表面；强调色 2–3 个；卡片圆角 6–10 px；同一屏可出现 5 组以上彩色图表；标签字号 10–12 px。  
- 链接：https://www.izotope.com/en/products/ozone.html

### 5. Valhalla DSP VintageVerb
- 借什么：极简、单一主面板、控制密度低；一屏只要求用户做一件事。  
- 不借什么：复古拟物纹理、木纹/金属装饰、深色到纯黑的背景。  
- 可量化特征（推断）：1 层主面板 + 少量控件；强调色基本为 1 个；圆角接近 4 px；控件行高度 30–40 px；正文 11–13 px。  
- 链接：https://valhalladsp.com/shop/reverb/valhalla-vintage-verb/

### 6. sonible smart:EQ / balancer
- 借什么：深色哑光卡片、低对比分隔、把“学习/分析”做成一个明确动作；曲线和结果区不抢控件。  
- 不借什么：粉色/蓝色双强调色、卡片外发光、倾斜的展示角度（产品页摄影，不是插件内 UI）。  
- 可量化特征：2–3 层表面；强调色 1–2 个；圆角 4–8 px；卡片间距 8–12 px；标题 12–13 px，主读数 22–28 px。  
- 链接：https://www.sonible.com/en/balancer/  
- 截图：`docs/ui-refs/sonible-balancer.jpg`

### 7. Tokyo Dawn Labs TDR Nova
- 借什么：图表占主要面积，参数区是紧凑的仪器面板；数值与单位分层清楚，图表本身承担解释工作。  
- 不借什么：拟物金属旋钮、深蓝渐变、过多小型彩色标签、把每个参数都加上边框。  
- 可量化特征：2 层表面；强调色 1 个（黄/蓝）；圆角接近 3–4 px；顶部工具条 24–28 px；图表占 60% 高度；标签 10–11 px。  
- 链接：https://www.tokyodawn.net/tdr-nova/  
- 截图：`docs/ui-refs/tdr-nova.png`

### 8. Wavesfactory Trackspacer
- 借什么：单页、单任务、参数少；一个主视图 + 少量开关，用户不需要学习布局。  
- 不借什么：饱和色块、过多状态灯、把侧链信息做成装饰性图形。  
- 可量化特征（推断）：1–2 层表面；1 个强调色；圆角 4 px；控件行 28–32 px；主视图占 60% 以上。  
- 链接：https://www.wavesfactory.com/audio-plugins/trackspacer/

### 9. Soundtheory Gullfoss
- 借什么：把复杂的自动判断收成一个“主控制 + 反馈图”，界面安静，数值不抢图。  
- 不借什么：极简到缺少状态说明；没有明确的“为什么”提示。  
- 可量化特征（推断）：2 层表面；1 个暖色强调；圆角 8 px；主图占 50–60%；标签 10–12 px。  
- 链接：https://www.soundtheory.com/home

### 10. Klevgrand 系列
- 借什么：统一的圆角和字号档位，控件有“手感”但不靠大面积渐变；图标风格一致。  
- 不借什么：插画化装饰、暖色大面积背景、拟物纹理。  
- 可量化特征（推断）：2 层表面；强调色 1 个；圆角 4–8 px；控件 28–32 px；图标注 10–11 px。  
- 链接：https://klevgrand.com/products/

## 反面参考（明确避开）

- **信息过载型**：Ozone 11 的多模块同屏、多个高饱和图表同时出现。问题不是功能多，而是同一层级出现了太多“重要”的东西。MasterLens 的规则是：一屏只允许一个主结论，其余降为次级文本或可展开区。
- **拟物/装饰型**：TDR Nova 的金属旋钮、Valhalla 的复古材质，以及产品页里的倾斜摄影。MasterLens 保留“仪器感”，但不做拟物旋钮、不做倾斜、不做彩色阴影。
- **蓝色科技仪表盘型**（旧版 MasterLens 自身）：深蓝底 + 亮蓝强调 + 每个数字一个彩色胶囊，像 2015 年的监控面板。2.0.1 全部移除。

## 调研结论（落到 tokens）

| 项目 | 规则 |
| --- | --- |
| 表面层数 | 3 层：底 `#141517`、面板 `#1A1B1E`、浮起 `#202226`；靠明度分层，卡片不描边 |
| 强调色数量 | 1 个：`#C2703C`；hover `#D07C45`；弱化 `rgba(194,112,60,0.14)`；一屏可视强调 ≤ 3 处 |
| 语义色 | 只用于状态点、4 px 状态横线、小标签：good `#6FA36F`、warn `#C99A3F`、bad `#C25B5B` |
| 圆角 | 2 档：控件 4 px、面板 8 px |
| 字号 | 11 / 12 / 13 / 16 / 28–34；读数用等宽 tabular，单位 11 px 且最弱一级 |
| 间距 | 8 pt 网格：外边距 16、面板内边距 16、行高 36、控件 28–32 |
| 分隔线 | 只在表格行、时间轴、区块之间，1 px `rgba(255,255,255,0.07)` |
| 动效 | hover 120 ms、状态 160 ms、面板出现 180 ms，ease-out；不做 spring / 循环 |
| 图标 | 1.5 px 描边、16 px 网格、圆角端点、单色；不用 emoji |

## 借鉴 / 不借鉴一句话总结

- **借鉴**：soothe 的图优先与留白；Pro-Q 的“图是主界面”；Pro-L 的“目标 + 危险区同刻度”；sonible 的哑光深色表面和克制的层级。
- **不借鉴**：soothe 的浅蓝紫、Pro-Q/Pro-L 的亮蓝品牌色、TDR/Valhalla 的拟物材质、Ozone 的同屏信息密度、产品页的倾斜摄影与发光。
