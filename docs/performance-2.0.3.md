# MasterLens 2.0.3：音频、显示节拍与验证记录

## 测试范围

同一台 Linux x86_64 云机器，Debian 13，GCC 14.2，JUCE 8.0.15，Release；可用 5 个 CPU，32 GiB 内存。2.0.2 使用基线提交 `56706f7` 构建并保留的二进制，2.0.3 使用本次修改后的二进制。编译停止后交替执行旧版 / 新版，没有同时运行两个构建器。

音频基准为固定随机种子、立体声 48 kHz、512 样本块。DSP 每轮处理 60 秒音频；关闭编辑器的完整 processBlock 每轮处理 30 秒。各做三轮，以下使用中位数。百分比是 wall time / 音频时长，表示本机单核处理预算，不是 DAW 的 CPU 指示器。

界面为 Xvfb + JUCE Linux 软件绘制，1120×700 基础尺寸。UiShot 先送入 200 秒固定合成音频，然后测五秒消息循环，并将整个组件树绘制到复用图像 30 次。计时器计数是实际执行的显示更新次数，**不是屏幕呈现 FPS**。该 UI 采样阶段没有持续送入新音频；它验证调度和绘制成本，不能替代真实 DAW 播放测试。

## 音频结果

| 场景 | 2.0.2 | 2.0.3 | 耗时下降 |
| --- | ---: | ---: | ---: |
| DSP / 60 s 音频 | 0.629 s / 1.05% | 0.345 s / 0.57% | 45.2% |
| 编辑器关闭，完整回调 / 30 s | 0.314 s / 1.05% | 0.165 s / 0.55% | 47.5% |

原始 DSP 样本：2.0.2 为 0.629 / 0.622 / 0.645 s；2.0.3 为 0.343 / 0.345 / 0.350 s。完整回调分别为 0.314 / 0.310 / 0.314 s，以及 0.165 / 0.163 / 0.167 s。

改动集中在两处：

- 真峰值 FIR 使用镜像历史窗口，移除每个 tap 的环形索引；四相按同一 tap 并行累加，保持每相的累加顺序和原来的系数。
- 试听历史按连续跨度复制，回绕时再分段；默认捕获路径不再逐样本进行整数取模。

没有降低过采样倍数、减少滤波器 tap、改变响度门限或跳过测量。完整 processBlock 基准同时验证默认输出逐样本相等与报告延迟为 0；没有加入全局分配拦截器。

## UI 结果

| 页面 | 2.0.2 paint p50 / p95 | 2.0.3 paint p50 / p95 | 2.0.3 显示更新 |
| --- | ---: | ---: | ---: |
| 响度 | 8.13 / 11.67 ms | 7.36 / 8.43 ms | M/S、主读数 62.0 Hz |
| 频谱 | 10.34 / 11.52 ms | 9.09 / 12.57 ms | 主读数 62.1 Hz，FFT 约半速 |
| 声场 | 7.98 / 8.80 ms | 7.66 / 12.77 ms | 声场、主读数 62.1 Hz |

响度页的整帧 p95 降低约 28%。频谱和声场 p50 略低，p95 高于旧版；新增的大幅图表、弧尺和相位指针有绘制开销，三页本次 p95 都处在 16.7 ms 的参考预算内。不据此声称每个平台都能稳定呈现 60 FPS。

旧版存在多层节流：主读数每三次更新一次；声场先按页面减半，再每三次更新。新版四个动态页面使用完整显示节拍，静态报告可半速；FFT 保持较慢节拍，事件与归因约 5 Hz，历史数据约 10 Hz。显示插值不提高测量源数据的采样频率，也不改报告数值。

M/S 按时间计算攻击 / 释放，声场统计量用 120 ms 指数平滑。隐藏的真实窗口停止 UI 工作；保持模式不运行 FFT。绘制使用固定边缘阴影与缓存图表背景，没有实时模糊。

## 回归结果

- **75 项 DSP 断言全部通过**，含既有响度、真峰值、44.1 / 48 / 88.2 / 96 kHz 文件分析、参考重采样、宿主时间和试听检查。
- 新增 32,768 个样本的 FIR 直接卷积对照，覆盖随机输入、脉冲、环形回绕；最大误差在 1e-6 内。清零后镜像历史返回精确零。
- 同一份 48 kHz / 16-bit 单声道 997 Hz、−20 dBFS WAV，经两个 CLI 分析，完整 JSON 除 `version` / `generatedAt` 外一致。校准为约 −23.0 LUFS、−20.0 dBTP、100% 覆盖度。
- 完整回调默认逐位旁路与零延迟检查通过。
- Linux VST3 / Standalone 构建成功，VST3 元数据为 MasterLens 2.0.3，链接的共享库全部可解析。
- 十一个页面、English、浅色、空态、关于、设置、专辑采集、真实文件 QC、频谱图，以及 880×560 与 125% 缩放均进行实际渲染和可见子控件越界检查。
- 125% 的窗口拖拽角重复缩放已修正；相位 / 宽度条原有的零或负高度轨道也已修正。

截图使用本次真实 UiShot，不经过图片重绘或合成。固定合成音频不代表商业母带质量。各 PNG 的尺寸、SHA-256 和渲染器 SHA-256 在 [screenshots-2.0.3.json](screenshots-2.0.3.json)，可用 `scripts/capture_ui.py --build-dir build-linux` 重建。

## 原生发布与未覆盖项

macOS / Windows 原生安装包由仓库 CI 构建，macOS runner 从正在退役的 `macos-14` 迁移至 `macos-15`。macOS 与 Windows x64 执行 DSP 回归，Windows ARM64 交叉构建。只有三个安装包目标全部成功才创建 Release 并上传 SHA256SUMS。

本机验证不是 macOS / Windows 的 DAW 或音频硬件回归。未在本机执行 auval、商业签名、公证、屏幕垂直同步或真实宿主的 GPU / 音频并发压力测试。原生构建结果以该版本关联的 GitHub Actions 记录为准。
