调研日期：2026-11-02。只把公开资料能支持的事情写进来；下面的产品比较不是完整功能清单，也不据此声称别的产品没有某项能力。

2.1 的差异化落在组合：**样本地址 → 频段后果 → 增益可行性 → 源文件 SHA256 → 专辑证明与 CLI 门禁**。每一项都能在普通电脑上用确定性算法运行，不需要训练集、模型权重、云端推理或外部编码器。它面向独立母带交付；不以一版更新宣称已经替代专业工作室的全部 QC 系统。

## 官方规则与本机情景分开

[Spotify 的归一化说明](https://support.spotify.com/ps-en/artists/article/loudness-normalization/)明确给出普通模式的目标与峰值余量：例如 −20 LUFS / −5 dBTP 的文件只提升到约 −16 LUFS。普通模式不能一概描述成“为了达到目标，服务端一定限幅”。Loud 模式的限幅是另一种设置。2.1 因此把表格改成安全增益、预计峰值和目标差额。

[Apple Digital Masters 官方页面](https://www.apple.com/apple-music/apple-digital-masters/)提供高质量母带和编码检查工具。[官方技术文档](https://www.apple.com/apple-music/apple-digital-masters/docs/apple-digital-masters.pdf)不支持把原先写死的“每首曲尾至少一秒数字静音”当成普遍门禁。本版移除了这条硬性要求。其他平台的静态 LUFS 数字仍是本机比较情景，不能保证真实播放端的设置、编码或归一化行为。

## 新检查怎么计算

- **头尾静音**：按所有声道的绝对峰值是否高于 −80 dBFS，定位首末有效样本，记录样本下标和秒数。不是自动剪辑建议。
- **内部数字静音**：所有声道同时低于等效零值 `1e-9`、连续至少 10 ms，并且不属于文件首尾。列为需要试听的提示；停顿、剪辑和掉音可能有相同的数学表现。
- **连续满刻度样本**：按源位深计算满刻度阈值，至少连续三个样本才形成阻断证据。它是可复核的样本事实，不能据此判定所有失真或限幅器类型。
- **直流与边界**：整文件每声道均值绝对值高于 0.1% 提示、高于 1% 阻断；首末样本绝对值高于 1% 提醒检查淡入淡出。音乐低频、短文件和有意硬切仍需人工判断。
- **坏数据**：NaN / Inf、解码失败、多于两声道的文件明确返回错误，不给出成功或 100% 覆盖的结果。失败文件不会加入成功的专辑快照。
- **分频折叠**：8192 点 Hann 窗、50% 重叠；分别计算 L / R 的复数 FFT。立体声能量 `P=(|L|²+|R|²)/2`，折叠能量 `M=|(L+R)/2|²`，损失 `−10 log10(M/P)`。同相为 0 dB，无关声道约 3 dB，完全反相显示上限 60 dB。频段占总能量不足 0.1% 时不参与最差频段排名；6 dB 以上提示试听。报告同时保留频段范围、Side 比例和能量占比。
- **增益预算**：`requested=target−I`，`safe=min(requested, ceiling−TP)`；预计响度 `I+safe`，目标差额 `target−(I+safe)`。恒定增益后的响度受绝对门限影响，标作估算；不渲染限幅、转码或音频文件。
- **证据**：流式 SHA256 对源文件完整字节计算；大小 / 修改时间在分析期间变化会报错。事件列表最多 128 条，完整计数独立保留，报告记录省略数量。SHA256 用于核对测量来源，不是签名或第三方认证。

这些工作只在离线线程进行；音频回调没有增加分配、锁或新分析器。默认旁路和监听开关沿用原有路径。

## 输出与兼容

CLI 的顶层文件报告使用 schema 3；新增 `forensic` 和 `gainBudget`，原有基础测量字段保留。GUI「导出 QC」输出 CSV + JSON；总报告 JSON 的 `fileQC` 同步带上这些内容。专辑 `fileForensics` 随宿主状态保存，并进入已有证明哈希；旧专辑没有此字段时仍可读取。

平台 JSON 中 `serviceLimitingDb` 保留作兼容别名，明确标记 `serviceLimitingDbIsLegacyShortfall`；新消费者使用 `targetShortfallLu`。`predictedTpBeforeLimiter` 同样是旧字段名，表示未施加峰值约束的目标情景；本版没有模拟服务端限幅器。`gainDb` 现在是峰值约束后的增益，`requestedGainDb` 是目标所需增益。

CLI 默认只检查读取与写报告是否成功。`--fail-on error` 才启用样本阻断 / 自选峰值上限门禁；`--fail-on warning` 进一步包含提示与显著的分频折叠损失。退出码 0 / 1 / 2 分别是完成 / 输入、解码或写报告错误 / QC 未通过。内部静音不自动等同损坏文件。
