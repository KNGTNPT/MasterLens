# MasterLens 2.1：证据、界面与验证记录

## 测试范围

本机为 Apple M3、macOS 27.2、Apple Clang 17、JUCE 8.0.15，Release / arm64。本版与上一版的 Linux 云机器不同，下面只记录本机实际结果，不把跨机器差异写成优化百分比。

音频输入为固定合成信号，48 kHz / 立体声 / 512 样本块。编译停止后串行运行三轮 DSP 与关闭编辑器的完整回调；音频预算使用处理 wall time / 音频时长，不是 DAW CPU 表。

## 音频与证据

- **103 项 DSP / 证据断言通过**：包括原有响度、真峰值、参考、试听和宿主时间，以及样本地址、跨块连续段、直流、非有限数据、证据上限、增益预算、专辑证明保存与恢复。
- **41 项 CLI 集成检查通过**：44.1 / 48 / 96 kHz 的同相与反相信号、能量保持、分频抵消、SHA256 对照、CSV 解析、数字静音地址、门禁退出码、坏文件、多声道和写报告失败。
- 60 秒音频的 DSP 耗时三轮为 **0.162 / 0.158 / 0.163 s**，中位数约 **0.27% 单核预算**。
- 关闭编辑器的完整 `processBlock`，30 秒音频三轮均约 **0.080 s / 0.27%**；默认逐样本输出相等、报告延迟 0 的检查通过。

分频检查使用解析信号验证数学关系，没有借测试数据训练模型。新检查在文件工作线程运行，实时音频路径沿用 2.0.3。阈值和公式见 [调研与算法说明](research-2.1.0.md)。

## UI 采样

真实 UiShot 编辑器，基础窗口 1120×700。先送入 200 秒固定合成音频，再测约五秒消息循环，最后把整个组件树绘制到复用图像 30 次。采样期间没有持续输入新音频，不能代表 DAW 中音频与显示并发的负载。

| 页面 | paint p50 | paint p95 | 最慢一帧 | 主读数更新 |
| --- | ---: | ---: | ---: | ---: |
| 响度 | 3.82 ms | 4.29 ms | 43.44 ms | 50.5 Hz |
| 频谱 | 5.74 ms | 5.95 ms | 44.97 ms | 50.3 Hz |
| 声场 | 2.99 ms | 3.21 ms | 46.18 ms | 51.3 Hz |

30 次采样中保留首次字体 / 绘图缓存开销，因此最慢一帧明显高于 p95。更新计数是消息线程实际执行次数，**不是屏幕呈现 FPS**，不据此声称所有宿主稳定 60 FPS。浅光影使用渐变、边缘高光和固定阴影，没有每帧模糊。

## 排版与截图

`python3 scripts/check_ui.py --build-dir build` 串行检查 **35 个真实布局场景**：11 页最小 880×560；主页面、设置与增益预算的 100 / 125 / 150 / 175 / 200% 缩放；另外覆盖英文、浅色、关于、空态和两个文件详情页。可见子控件越界检查通过；同时人工查看了截图，修正最小窗口左侧标签与数字挤压、英文按钮宽度，以及恢复英文设置时子页面按钮仍显示中文的问题。几何检查不能证明每个文本像素都没有碰撞，仍保留实际截图供复核。

README 的 18 张截图由实际编辑器直接输出，没有重绘界面。截图音频是固定合成信号，文件示例含人为设置的反相与 25 ms 停顿。图片尺寸、SHA256 与渲染器指纹见 [screenshots-2.1.0.json](screenshots-2.1.0.json)，布局命令与结果见 [layout-2.1.0.json](layout-2.1.0.json)。

```bash
python3 scripts/capture_ui.py --build-dir build
python3 scripts/check_ui.py --build-dir build
```

## 发布范围

本机构建 AU、VST3、独立版、CLI、DSP 测试和 UiShot。正式安装包由仓库 GitHub Actions 构建：macOS 通用 arm64 / x86_64，Windows x64，以及 Windows ARM64。macOS 和 Windows x64 执行 DSP 与 CLI 回归；Windows ARM64 在 x64 runner 上交叉编译，不声称做过 ARM64 实机运行验证。

只有三个发布目标全部成功才创建 Release，并生成 `SHA256SUMS.txt`。以 [v2.1.0 对应 Actions](https://github.com/KNGTNPT/MasterLens/actions) 和 [Release](https://github.com/KNGTNPT/MasterLens/releases/tag/v2.1.0) 为正式构建结果。

未覆盖 DAW / 音频硬件压力测试、auval、商业代码签名和 Apple 公证。离屏测试、编译与校验和均不等同于这些验证。
