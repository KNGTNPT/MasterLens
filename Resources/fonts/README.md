# Geist font assets

Unmodified Geist Regular, Medium, Bold and Geist Mono Regular OTF files from [vercel/geist-font](https://github.com/vercel/geist-font), pinned to commit `2e554ff2ea3979b63afe770af6424eb8b9490a74`.

Redistributed under the SIL Open Font License 1.1 in [OFL.txt](OFL.txt). CMake embeds the files in `MasterLensFonts`; no user-installed Latin font or network access is needed at runtime. CJK fallback remains explicit in `Source/ui/Theme.cpp`.

Geist Mono Regular is reserved for the 11px header byline; measurement labels and values retain their existing Geist roles.
